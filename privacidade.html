Política de Privacidade

Atualizada em 1º de novembro de 2026.

O que acessamos

Somente estatísticas agregadas do canal Noema no YouTube, com o escopo de leitura yt-analytics.readonly e youtube.readonly, autorizado pelo próprio dono do canal.

Como usamos

Para gerar relatórios internos de desempenho dos vídeos. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Onde guardamos

Em servidor privado do dono do canal. A credencial de acesso fica em arquivo protegido, nunca em repositório público. Não guardamos dados pessoais de espectadores, só números agregados.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
